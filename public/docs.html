Sona in Claude.

Connect Sona to Claude with MCP and search outlier posts, hooks and decodes from the chat.

Sona indexes high-performing posts and videos from entrepreneurs and creators, with real engagement figures. The MCP server exposes that index to any Model Context Protocol client — search it for proven hooks, then decode a post to get the reusable pattern behind it.

Endpoint

https://buildwithsona.com/api/mcp — Streamable HTTP, JSON-RPC 2.0. No API key; the index is public and read-only.

Connect to Claude

Add Sona as a custom connector, then ask Claude to search your niche.

  1. Open Claude → Settings → Connectors
  2. Choose Add custom connector
  3. Paste https://buildwithsona.com/api/mcp
  4. Save. Claude will list three Sona tools.

You can also copy the endpoint from Settings → MCP inside the studio.

Quick Start

Every call is a JSON-RPC 2.0 POST. List the tools first:

List toolsbash
curl -X POST https://buildwithsona.com/api/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

search_outliers

Search the curated feed. Each result carries its real engagement figure and, where one was computed, an outlier multiple against that creator's own baseline.

ParameterTypeNotes
querystringFree text matched against post text and creator
catstringfounders, writers or creators
media_typestringimage or video
limitintegerMaximum results to return
Calljson
{
  "jsonrpc": "2.0", "id": 2, "method": "tools/call",
  "params": {
    "name": "search_outliers",
    "arguments": { "query": "one-person business", "cat": "founders", "limit": 5 }
  }
}

get_outlier

Fetch a single post by id, including its source URL and every stored field. Use it after search_outliers when you want the full record.

ParameterTypeNotes
idstringRequired. The id returned by search_outliers

decode_post

Break a post down into the mechanism that made it work: hook type, the tension that stops the scroll, the payoff, and a reusable pattern you can write from. Works on any text, not only posts in the index.

ParameterTypeNotes
textstringRequired. The post to decode, 10–2000 characters
Decodes are cached

Results are keyed by a hash of the text, so decoding the same post twice costs one call, not two.

Protocol

Streamable HTTP transport, JSON-RPC 2.0. Send Accept: application/json, text/event-stream; responses may arrive as either. initialize reports server name sona-mcp, version 1.0.0.
